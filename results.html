Reading the results

What the table
is telling you.

Every quantity the tool reports is defined here, together with what it does and does not license you to conclude, and how to check the items that need a human eye.

The item table, column by column

One row per recording. Rows can be sorted by participant and item, by lowest accuracy, or by lowest confidence — the last two are the fastest way into the items that need checking.

ColumnWhat it contains
Participant Read from the file name when it follows participantID_itemNN; otherwise whatever you assigned by hand in the file table.
Item The item number, which is what links the recording to a target sentence.
Target Your target sentence after normalization — lowercased, punctuation stripped, and with the scoring rules applied. This is the string the comparison actually uses, not the string you pasted in.
Whisper The transcription after the same normalization, with the alignment against the target marked (see below). Hovering a marked word shows what it was aligned to.
Accuracy 100 × (1 − WER), in percent.
WER Word error rate: (S + D + I) / N over a word-level minimum-edit alignment, where N is the number of words in the normalized target. Truncated at 1.0.
Confidence The model's own certainty about the transcription: the mean probability of the tokens it selected, shown as a percentage, with the raw mean log probability beneath it.
Audio Plays the recording for that row, so a questionable item can be checked without leaving the table.

How the alignment is marked

The three edit types that enter the word error rate are marked directly in the transcription, so a score can be traced to the words that produced it.

white Substitution. A word produced in place of a target word. Hover to see the target word it replaced.
of Insertion. A word in the transcription with no counterpart in the target.
▲ Omission. A target word with no counterpart in the transcription. Hover to see which word is missing.
unmarked A match. Matches contribute nothing to the error rate.
Target (7 words)
the streets in this city are wide
Whisper
the streets in the city are white

Two substitutions, no insertions, no omissions, over seven target words: WER = 2 / 7 = .286, accuracy = 71.4 %.

Because normalization is applied to both strings before comparison, capitalization, punctuation, and whichever variants you configured never affect the score. A response that is correct but differently punctuated scores as a match; a response that substitutes a grammatical morpheme does not.

The per-participant summary

Above the item table, one row per participant reports the number of items scored (against the number of target items, when a target set is loaded), and the mean accuracy, mean word error rate, and mean confidence across that participant's items.

The means are taken over items that were actually scored. If a recording is missing or failed, the count tells you so — check it before treating a participant mean as comparable to the others.

What the numbers do and do not license

Accuracy has a floor

Word error rate is truncated at 1.0, following the standard definition. A response with more errors than there are target words therefore scores 0 % accuracy rather than a negative value. Very disfluent responses are consequently not distinguished from silent ones by the score alone.

Confidence is not a probability of being correct

Confidence is internal to the model: the mean probability assigned to the tokens it chose. It is comparable across items processed in the same session with the same model and decoding settings, and it is not comparable across different checkpoints or decoding strategies. A high figure means the model was not hesitating, which is not the same as being right.

The combination is what is informative. Low accuracy with high confidence usually means the participant really did produce something different from the target — the score is doing its job. Low accuracy with low confidence more often points to the recording: background noise, a clipped onset, a boundary placed in the wrong spot. Those are the rows to open the audio on.

An empty transcription is ambiguous

An item with no recognized speech is scored WER 1.0 and 0 % accuracy. That is correct if the participant said nothing, and wrong if the segment boundary was misplaced or the file is silent for another reason. Inspect these directly rather than reading them as non-responses.

Automatic scores still need a human subsample

Whisper transcribes toward an intended reading and can normalize morphosyntactic detail toward more expected forms — precisely the deviations an elicited imitation task measures. See the speech recognition page for the evidence. Report the agreement between the automatic scores and a human-verified subsample; the citation page gives a methods-section template that includes it.

Checking efficiently

The table is built for triage rather than for reading every row.

  • Sort by lowest accuracy to see the items where the transcription and the target diverge most, and by lowest confidence to see the items where the model itself was least certain. The two orderings surface different problems.
  • Play the audio for any row you are unsure about; the button is in the last column.
  • Export to JSON when you intend to correct by hand. Each item carries a transcription_corrected field, a flag field, and a reviewed marker, so a corrected transcription can be recorded alongside the automatic one rather than replacing it.

What the exports contain

Both exports record the model and the scoring configuration alongside the scores, so a file is self-describing when it is deposited with the study materials.

CSV

participant, item, target, whisper, wer, accuracy_pct, confidence, avg_logprob, duration_s, file, model, rules. One row per item, in the order shown in the table.

JSON

The same item-level fields, plus the alignment operations themselves under ops, and a meta block recording the Whisper model, the decoding description, how confidence was computed, the full scoring-rule configuration, the number of target items, and a timestamp. The fields for human review described above are included.
