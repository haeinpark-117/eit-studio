How to cite

Cite the tool,
report the settings.

Automatic scoring is only useful if a reader can state precisely what was done. This page gives a citation for the tool, the recognition settings in full, and a template for the methods section.

Citing EIT Studio

For now, please cite the tool itself. No article describing EIT Studio has been published yet, so there is no journal reference to point to; citing a web-based tool as software is the appropriate practice in the meantime.

A publication describing the tool and its validation is in preparation. A citable reference will be added here once it appears, and users will be asked to cite it instead.

APA 7
Park, H. I. (2026). EIT Studio [Computer software].
    https://haeinpark-117.github.io/eit-studio/

The bracketed descriptor stays [Computer software] because that is the category APA 7 provides for programs of this kind; in prose the tool is described as a web-based tool, which is the more informative term for a methods section.

BibTeX
@misc{park2026eitstudio,
  author = {Park, Hae In},
  title  = {{EIT} {Studio}},
  year   = {2026},
  note   = {Computer software},
  url    = {https://haeinpark-117.github.io/eit-studio/}
}

What to report in your methods section

Responses were transcribed automatically using Whisper large-v3-turbo
running locally in the browser via EIT Studio (Park, 2026). Accuracy was
operationalized as one minus the word error rate, computed over a
word-level minimum-edit alignment as (S + D + I) / N and truncated at
1.0. Decoding was greedy (do_sample = false, num_beams = 1,
temperature = 0) with the language fixed to English; no prompt or
target-sentence bias was supplied, and each recording was decoded
independently. Prior to comparison, both the target sentence and the
transcription were lowercased, stripped of punctuation, and normalized by
[expanding numbers to words / expanding contractions / applying the
lexical variants listed in the scoring configuration]; possessive 's was
preserved. The full scoring configuration is available at [repository
link]. A randomly selected [N] % subsample was transcribed and scored by
a human rater; agreement was [statistic].

The recognition settings referred to in that paragraph are documented in full on the speech recognition page, and should be reported alongside it.

Automatic transcription does not replace human verification. Reporting a human-verified subsample lets readers judge how much the automated procedure contributed to the results.

EIT Studio is a web-based scoring tool, not an instrument. Cite the task separately, using the source of your own sentence set.
