How to cite

report the settings.

Automatic scoring is only useful if a reader can state precisely what was done. This page gives a citation for the tool, the recognition settings in full, and a template for the methods section.

Citing EIT Studio

For now, please cite the website itself. No article describing EIT Studio has been published yet, so there is no journal reference to point to; citing the site as software is the appropriate practice in the meantime.

A publication describing the tool and its validation is in preparation. A citable reference will be added here once it appears, and users will be asked to cite it instead.

The recognition settings, in full

These are fixed rather than exposed as options, because varying them would make scores incomparable across studies. Reporting them is what allows a reader to reproduce the procedure.

Model onnx-community/whisper-large-v3-turbo, run in the browser through transformers.js. Encoder in fp16 and decoder quantised to q4 on WebGPU; WASM at q8 where WebGPU is unavailable.
Decoding Greedy search — do_sample = false, num_beams = 1, temperature = 0. The task calls for verbatim repetition of what the participant produced, so the decoding must be deterministic: the same recording yields the same transcription every time. Sampling would introduce run-to-run variation into the score itself, and beam search would let a globally more fluent hypothesis override a locally accurate one.
No prompt, no bias The recognizer is never given the target sentence, and no vocabulary or initial prompt is supplied. This is the single most important setting: constraining recognition toward the expected words would make the transcription converge on the target and erase the deviations that constitute the measurement.
No cross-item context Each recording is decoded independently, with no conditioning on previously decoded text. One item's transcription therefore cannot influence the next, and the order in which files are processed does not affect the result.
Language Fixed to English (language = "en", task = "transcribe"). Leaving language detection to the model risks it identifying a strongly accented response as the speaker's first language; fixing it removes that failure mode. The translate task is never used.
Audio Resampled to 16 kHz mono, the rate Whisper operates at, with a cap of 128 generated tokens — ample for a single-sentence response and a guard against runaway repetition.
Confidence Not produced by the model directly. A logits processor records the distribution at each decoding step, and the reported figure is the mean log probability of the tokens actually chosen, shown both as a probability and in raw form. It is comparable within a session but not across checkpoints or decoding strategies.

What to report in your methods section

Responses were transcribed automatically using Whisper large-v3-turbo
running locally in the browser via EIT Studio (Park, 2026). Accuracy was
operationalized as one minus the word error rate, computed over a word-level
minimum-edit alignment as (S + D + I) / N and truncated at 1.0. Decoding was
greedy (do_sample = false, num_beams = 1, temperature = 0) with the language
fixed to English; no prompt or target-sentence bias was supplied, and each
recording was decoded independently. Prior to
comparison, both the target sentence and the transcription were lowercased,
stripped of punctuation, and normalized by [expanding numbers to words /
expanding contractions / applying the lexical variants listed in the
scoring configuration]; possessive 's was preserved. The full scoring
configuration is available at [repository link]. A randomly selected
[N] % subsample was transcribed and scored by a human rater; agreement
was [statistic].

Automatic transcription does not replace human verification. Reporting a human-verified subsample lets readers judge how much the automated procedure contributed to the results.

EIT Studio is scoring software, not an instrument. Cite the task separately — Ortega et al. (2002) for the included English preset, or the source of your own sentence set.

Reference

Ortega, L., Iwashita, N., Norris, J. M., & Rabie, S. (2002, October). An investigation of elicited imitation tasks in crosslinguistic SLA research [Paper presentation]. Second Language Research Forum, Toronto, Canada.
