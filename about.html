About

An open instrument for elicited imitation research.

EIT Studio began as an English-language tool. The goal is a resource that serves elicited imitation research in any language for which validated materials exist.

The vision

Elicited imitation tasks have been developed in many languages, but the infrastructure for administering and scoring them has remained local to individual laboratories. Each research team rebuilds the same pipeline, and scoring procedures diverge in ways that make findings difficult to compare across studies.

EIT Studio is an attempt to make that infrastructure shared. The tool is deliberately instrument-agnostic: researchers load their own target sentences and their own normalization rules, so it fits the instrument a study actually uses rather than imposing a fixed one. Everything runs in the browser, so there is no cost of operation, no account, and no transfer of participant audio.

Now

English

Automated transcription and word error rate scoring for English elicited imitation tasks, with any target sentence set the researcher supplies.

Next

Task administration

A companion module for delivering the task itself, so that researchers can administer their own audio stimuli and collect responses in the same environment.

Goal

Additional languages

Support for further languages, each added only once the scoring procedure has been examined for that language rather than assumed to transfer from English.

Why the tool is currently limited to English

The speech recognition model underlying EIT Studio is multilingual, so transcription in other languages is technically available. Two considerations argue against enabling it before the relevant work has been done. First, word error rate is computed over whitespace-delimited words, which does not carry the same interpretation in languages that do not mark word boundaries with spaces, or in agglutinative languages where a single particle error marks an entire eojeol as incorrect. Second, published evidence on the agreement between automatic and human scoring of elicited imitation is currently available for English (McGuire & Larson-Hall, 2025) and not, to our knowledge, for other languages. Enabling a language before its scoring behavior has been examined would invite exactly the kind of undocumented procedural variation that this tool is intended to reduce.

Contributing elicited imitation materials

Extending the tool to another language requires validated materials, not merely a model that can transcribe it.

If you have developed and published an elicited imitation task in a language other than English and would be willing to make the materials available, please get in touch. Contributions of the following kinds are especially useful.

  • Target sentence sets, with item numbers and syllable counts where available
  • Audio stimuli, together with the timing parameters used in administration
  • Scoring rubrics or normalization conventions applied in the published study
  • Response data with human scores, which would permit examination of agreement between automatic and human scoring in that language
  • Independent proficiency scores for the same participants — for example, a standardized test, an institutional placement measure, or a C-test — which would permit examination of concurrent validity between the automated scores and an external criterion

Contributors retain authorship and credit. Materials will be attributed to their original publication wherever they appear in the tool, in the same way that the English preset is attributed to Ortega et al. (2002), and nothing is incorporated without the explicit agreement of the researchers who developed it.

Enquiries about collaboration, validation studies in additional languages, or institutional use are equally welcome.

How to cite EIT Studio

If the tool contributed to the analysis reported in your study, please cite it and report the model and the scoring configuration you used. Exporting the rule set from Step 2 and depositing that JSON file with your study materials makes the scoring procedure fully reproducible.

What to report in your methods section

A description along the following lines states everything a reader needs in order to evaluate or reproduce the scoring procedure. Replace the bracketed material with the values that apply to your study.

Responses were transcribed automatically using Whisper large-v3-turbo
running locally in the browser via EIT Studio (Park, 2026). Accuracy was
operationalized as one minus the word error rate, computed over a word-level
minimum-edit alignment as (S + D + I) / N and truncated at 1.0. Prior to
comparison, both the target sentence and the transcription were lowercased,
stripped of punctuation, and normalized by [expanding numbers to words /
expanding contractions / applying the lexical variants listed in the
scoring configuration]; possessive 's was preserved. The full scoring
configuration is available at [repository link]. A randomly selected
[N] % subsample was transcribed and scored by a human rater; agreement
was [statistic].

Automatic transcription does not replace human verification. Reporting a human-verified subsample alongside automatically scored data allows readers to evaluate how much the automated procedure contributed to the reported results.

Citing the instrument as well as the tool

EIT Studio is scoring software, not an instrument. The elicited imitation task itself should be cited separately. Studies using the included English preset should cite Ortega et al. (2002); studies using their own sentence set should cite its source.
